    How to collect another Windows computer

    Download the collector on the computer being investigated. Open Windows PowerShell as its signed-in user and run:

    powershell.exe -NoProfile -File "$env:USERPROFILE\Downloads\Collect-Entity360Device.ps1"

    It saves a JSON file on that user’s Desktop. Import that JSON here. It reads local configuration without tenant sign-in. Windows execution policy may require reviewing and unblocking the downloaded script first.
